# Security Policy

## Scope

AATM is an educational terminal simulation. It is not suitable for real financial transactions or storage of banking credentials.

## Reporting

Do not open a public issue containing secrets or personal data. Contact the repository maintainer privately through GitHub's security reporting feature where available.

## Safe use

- Use fictional IDs and PINs only.
- Do not connect this demo to real accounts.
- Do not commit credentials, tokens, or personal financial data.
- A random in-memory balance is not an account ledger or a security control.
