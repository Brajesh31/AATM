# Contributing

1. Open an issue describing the defect or proposed improvement.
2. Keep changes focused and explain whether they affect the JavaScript or TypeScript flow.
3. Never add real credentials, banking data, or secrets.
4. Run the available checks and manually test prompt cancellation and invalid input.
5. Submit a pull request with the behavior change, validation performed, and known limitations.

Do not describe the simulation as connected to a bank or capable of real transactions.
