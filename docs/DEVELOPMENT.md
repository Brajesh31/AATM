# Development

1. Install Node.js 18 or later.
2. Run `npm ci` from the repository root.
3. Run the JavaScript flow with `node atm.js`.
4. If working on TypeScript, install/configure a TypeScript compiler or runner separately. The repository does not currently declare TypeScript as a development dependency.
5. Exercise every prompt branch, including invalid input and Ctrl+C cancellation.

Keep the JavaScript and TypeScript implementations behaviorally aligned. Replace the placeholder failing npm test script only when real tests are added.
